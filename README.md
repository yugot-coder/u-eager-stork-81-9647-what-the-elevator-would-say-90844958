The funniest one line a talking elevator could say, in the elevator's own voice — 79 characters, written for make.fun's "What the Elevator Would Say" bounty.

> The music in here isn't for you. It's so I don't have to listen to you breathe.

The joke: elevator music is the most elevator thing there is, and this line flips it — the muzak exists for the elevator's sake, not the passengers'. It lands on the first read, comes from the elevator's own job, and rests on no pun. Ten candidates were weighed in `CANDIDATES.md`; this one won.

## Run it

```sh
python3 main.py
python3 main.py --check
```

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only — nothing to install. `--check` re-reads the file and verifies it byte-for-byte against the expected SHA-256, length 1–120 characters, valid UTF-8, not only whitespace.
